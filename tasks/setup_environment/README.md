# Environment

Run `make` from `code/` to install missing R packages and record the declared package versions. Analysis scripts never install packages. Production uses R 4.5.2 and GNU Make 3.81 in the verified local build.

System tools: Bash, curl, unzip, shasum, Python 3, Graphviz (`dot`), and a TeX installation with `pdflatex`. Documents compile through their Makefiles. Restricted or historical source captures are documented in each acquisition task; credentials remain outside this repository.
