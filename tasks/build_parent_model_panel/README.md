# Build enhanced-parent model panels

This task is the single production definition of an enhanced parent. It joins
filings linked by conservative pre-filing evidence or by corroborated exact
parcel adjacency, sums proposed units, and aggregates site characteristics
across unique pre-filing lots.

The historical panel covers 2019–2023. The post-policy crosswalk extracts
2024–2026 DOB records, but the production panel limits both target and companion
filings to 2025 so the historical and post outcomes use the same calendar-year
construction. Parents with repeated nonmissing BIN rows are retained but marked
ineligible rather than corrected or imputed.
