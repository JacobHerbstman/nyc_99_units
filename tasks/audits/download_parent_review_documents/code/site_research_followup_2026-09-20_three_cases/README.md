# Three-case site follow-up, 2026-09-20

This acquisition note records first-party sources examined for the Lorimer,
Astoria 31st/30th Street, and Webster comparisons. The already archived DOF
maps and MTA board memo remain at their existing paths; they are not copied.
`sources.csv` distinguishes local original PDFs from first-party pages and
documents seen in the web index. `reused_originals.sha256` verifies the three
saved PDFs inspected directly. The NYPL and DEC PDF hosts returned DNS errors
to `curl` in this session, and direct web opens of NYPL PDFs returned HTTP 403,
so those PDFs are **not archived here**. Web-index excerpts are leads to check
against original pages before adopting a final site boundary.
