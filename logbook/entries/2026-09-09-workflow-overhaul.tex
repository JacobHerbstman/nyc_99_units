\section*{September 9, 2026: Rebuilding the research workflow}
\textit{Agent-drafted research entry.}

The workflow overhaul repairs the stale-result failures documented in the preceding review. It preserves the study's samples, parent-linkage decisions, exposure classification, and empirical methods. The main results still compare 2019--2022 with January 1, 2025--July 8, 2026. The joint size-and-splitting model remains the next research step; this cleanup does not estimate its parameters.

Make now checks each required upstream task before comparing the timestamps of its concrete outputs. The GNU Make 3.81 implementation needs an explicit empty recipe on those upstream file rules to read their updated timestamps in the same invocation. Missing companion outputs rerun their actual producer and its dependent task outputs through \texttt{all}. A real missing-file test caught a report that otherwise refreshed only on the next invocation because Make had cached the primary output's old timestamp. Recovery now also updates that report inside the same build. Shared execution rules serialize writers within a task, and the document entry points check the tasks that own their figures and numerical inputs. Routine file-size guards have been removed. Fixed-name results reject command-line specification overrides; changing a specification in its tracked Makefile makes the affected results stale explicitly.

All shared helpers and Make infrastructure now live in \texttt{tasks/shared/code/}. Acquisition, staging, and indexing are separate, explicit steps. The parcel loaders process named releases instead of searching the raw-data folders for an available version. One-use wrappers and unused download and file-discovery helpers were removed. Atomic writes publish a completed file; they no longer compare output bytes to decide whether Make should consider a result updated.
