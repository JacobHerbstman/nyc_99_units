# Summarize developer responses

This task produces the paper-facing design-response figures from initial DOB
NOW New Building filings. It compares total construction area, gross
construction square feet per unit, and the number of buildings and filings
within provisional BBL-year sites before and after the 485-x threshold.

Total construction area includes common, mechanical, parking, and
nonresidential space. It is not residential floor area or apartment size.
Likewise, a BBL-year is a descriptive site proxy rather than a legally
validated 485-x eligible site.
