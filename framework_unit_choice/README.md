# Original unit-choice framework

August 2026: *Developer Responses to New York City’s 100-Unit Threshold: A Notch-and-Kink Model*.

This is the framework in place before the September size-and-splitting note. It models the choice of total units with a notch and kink, without an endogenous splitting margin. The LaTeX source is preserved exactly from commit `1374dda` (`framework_writeup.tex`). Its empirical references and assumptions are those of that version.

Run `make` in this directory to rebuild `framework_unit_choice.pdf`. The current framework remains in `../framework_writeup.tex` and `../framework_writeup.pdf`.
