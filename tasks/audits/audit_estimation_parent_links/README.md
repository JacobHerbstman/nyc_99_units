# Review estimation parents and missed companions

This audit follows the current complete-characteristic, A/B, 50-plus-unit sample after applying the manual source decisions: 71 multi-constituent parents (23 historical and 48 post-policy), with 163 constituent rows. The original 76-parent review is preserved and remapped through filing IDs. One newly eligible existing parent has a saved-record review and an explicit pending independent-corroboration note.

`code/review_parents.R` assembles a case file for every parent from the saved membership, saved accepted link evidence, Housing Database records, and DOB initial filings. The review separates evidence of common development, whether filings represent distinct buildings, completeness of the parent, and the date/source of unit measurement. Hand-reviewed public-source evidence belongs in `code/parent_evidence.csv`; it is an audit ledger, not a production override.

`code/screen_neighbors.R` checks every estimation parent, including singletons, against positive-unit new-building records in the saved Housing Database (historical) and DOB initial filings (post-policy). It enumerates filings within 200 metres and 365 days of an existing member, plus same-lot matches regardless of distance. Existing members of the same parent are excluded. This broader source pool includes filings below six units and filings excluded by estimation characteristics. Geographic distance alone is not an accepted link. Missing coordinates and source coverage limit this screen; earlier/later phases outside the time window require separate contextual review.

Outputs are a readable casebook, constituent evidence, and a nearby-filings review queue, with deterministic data reports. Public sources are reviewed manually, with URLs and explicit limitations retained in the evidence ledger. No live web calls occur in a build. Inputs retain the project's recorded HDB 25Q4 and DOB July 2026 vintages.

The first reviewed baseline contains 168 constituent rows for the 76 parents and 1,238 parent-neighbor pairs from 970 anchor filings belonging to 876 estimation parents. Of these, all 137 pairs around the 76 multi-constituent parents have record-review notes in `code/neighbor_evidence.csv`. The other 1,101 are explicitly unadjudicated. Owner matches are exact normalized names, using the captured DOB owner when available and historical parcel ownership otherwise; different labels do not rule out common beneficial ownership.

The evidence ledger records five parents containing six withdrawn applications (368 units), three links subsequently separated by the manual source, seven reviewed missing-companion candidates around existing multi-constituent parents, and additional phase or ownership boundary questions. These findings are recommendations for producer corrections and sensitivity analysis, not production overrides. The casebook shows the individual records and remaining uncertainties.
