# Build Frozen Opportunity Lots

Creates the frozen pre-policy MapPLUTO tax-lot universe for the opportunity-site sales design.

The first version uses the latest usable MapPLUTO release safely available before June 15, 2022, computes residential capacity from `lotarea * residfar`, and flags the primary 50-unit opportunity universe using a transparent 850 gross-square-feet-per-unit rule.
