# LODES workplace construction sources

Public Census LODES8 New York WAC files, all private jobs (JT02), 2019–2023. S000 totals plus SE01/SE02/SE03 earnings segments; CNS04 identifies construction (NAICS 23). Also downloads the 2020-block geography crosswalk, release version and publisher SHA256 checksums. First acquisition September 8, 2026. Mutable URLs: unchanged builds retain the snapshot; refresh deliberately with report comparison. No credentials required. Sources are unchanged compressed bytes; each source gets a data report and checksum verification through Make. Run make in code/.

Documentation: https://lehd.ces.census.gov/doc/help/onthemap/LODESTechDoc.pdf
