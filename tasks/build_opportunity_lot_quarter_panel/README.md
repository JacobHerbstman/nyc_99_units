# Build Opportunity Lot-Quarter Panel

Creates the frozen primary opportunity-lot by calendar-quarter panel for sale-incidence and price-outcome analysis.

The panel has one row per primary opportunity BBL per calendar quarter. It carries frozen MapPLUTO opportunity-site characteristics, exact-BBL DOF sale indicators, and ACRIS site-sale indicators from the reviewed private-market sales layer.

ACRIS site-sale outcomes are recorded separately for primary private-market sales, strict private-market sales, and broad priced transfers. Allocated price outcomes are present only when the ACRIS event has a complete allocation denominator.
