# Opportunity Panel First Pass

This audit task summarizes what the current opportunity lot-quarter panel can
support before unresolved DOF-only sales are incorporated.

It uses the reviewed ACRIS private-market site-sale layer already embedded in
`build_opportunity_lot_quarter_panel`. The outputs are descriptive and
diagnostic only. They are not final paper tables.

The task reports sale counts and price coverage by policy period and capacity
exposure quartile, then estimates simple first-pass fixed-effect regressions for
sale incidence and log price per allowed residential square foot. Logged price
specifications use only strictly positive price observations.
