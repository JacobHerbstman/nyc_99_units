# HDB unit bunching

This production task creates the paper-facing motivation figures for the
99-unit response. It compares DCP Housing Database New Building applications
filed in 2025 with the annual average from 2010--23. The transition year 2024
is omitted.

The exact-count figure uses individual HDB applications. The histogram also
shows a provisional parent defined as a BBL by filing year. That aggregation
is descriptive and is not treated as a legally validated 485-x eligible site.
The wide-range figure preserves parent totals at 198, 297, and 396 units.

Robustness checks, alternative pre-periods, timing diagnostics, application
lists, and duplicate-site checks remain in
`tasks/audits/summarize_dcp_hdb_unit_bunching`.
