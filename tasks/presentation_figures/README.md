# Presentation figures

Slide versions of the main figures, without plot titles, for `slides/`.
`plot_bunching_reveal.R` draws the shares of A/B parents of 50 to 300 units by
exact size, out of all parents of at least 50 units in each period, from the
canonical parent panel: `parent_bunching_2019_2022.pdf` shows 2019--2022 alone
and `parent_bunching_both_periods.pdf` adds 2025--2026 on the same axes.

Run `make` in `code/`.
