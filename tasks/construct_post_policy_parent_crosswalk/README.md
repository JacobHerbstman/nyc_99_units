# Construct post-policy parent crosswalk fields

This task reduces DOB NOW initial New Building filings in 2024–2026 to the
fields needed to construct post-policy parents: root and filing identifiers,
units, filing BBL, leakage-safe lot history, normalized owner, and explicit
project references. The enhanced-parent task combines these fields with exact
MapPLUTO adjacency.

Manual case evidence and the investigative exact-99 casebook remain in
`tasks/audits/audit_developer_opportunity_crosswalk`.
