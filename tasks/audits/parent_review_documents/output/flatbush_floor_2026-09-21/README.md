# Flatbush earlier-building evidence

NYC Educational Construction Fund, February 2018 Draft Environmental Impact Statement, downloaded September 21, 2026. Part 2 physical PDF page 118 describes the three-story building on old lot 18; Part 3 physical page 1 (Figure 8-5) photographs it and distinguishes the neighboring two- and five-story buildings. These sources support a roughly uniform-height approximation, not an exact floor-area partition or an override of administrative housing units.

The original PDF bytes are held in the acquisition task's output directory. `sources.csv` records the literal public URLs, document vintage, retrieval date, byte counts and SHA-256 hashes. `flatbush_floor.make` downloads to temporary files, verifies the pinned hashes, and publishes only successful transfers. An ordinary unchanged build reuses the saved PDFs. Root `make flatbush-floor-review` retrieves these sources and runs the bounded calibration sensitivity in the existing parcel audit.
