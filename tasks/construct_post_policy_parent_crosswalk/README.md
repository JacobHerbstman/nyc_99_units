# Construct post-policy parent crosswalk fields

This task reduces DOB NOW initial New Building filings in 2022–2026 to the
fields needed to construct recent parents: root and filing identifiers, units,
filing BBL, leakage-safe lot history, normalized owner, and explicit project
references. The 2022 filings provide left-side linkage padding so that 2023
and 2024 can be constructed under the same 365-day rules as 2025 and 2026.
The parent-cohort task combines these fields with exact MapPLUTO adjacency and
its task-local manual linkage ledger.
